# SDK and CLI Reference (Packaged)

Summary of CLI entry points and SDK usage. This packaged reference gives a compact overview; full API docs live in the repository.

Key CLI commands:
- `payway-sdk demo` — run the simulated checkout
- `payway-sdk docs list` — list packaged topics
- `payway-sdk webhook trigger` — emit a signed fixture for testing
- `payway-sdk mcp` — start the MCP server (stdio)
