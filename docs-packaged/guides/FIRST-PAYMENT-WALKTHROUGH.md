# First Payment Walkthrough (Packaged)

This packaged summary describes the first-payment reference flow. For full step-by-step instructions, see the repository's `docs/guides/` sources.

- Create a sandbox credentialed profile
- Start the demo: `npm exec -- payway-sdk demo`
- Create a transaction, complete the UI flow, verify status with `payway-sdk check-transaction`
