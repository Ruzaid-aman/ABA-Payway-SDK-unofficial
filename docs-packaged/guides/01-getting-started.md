# Getting Started

This chapter provides a concise, packaged introduction for developers using the PayWay SDK and CLI.

- **Install:** Use the published package and follow the Quickstart in the CLI.
- **Run:** `npx payway-sdk <command>` or use the installed binary.
- **Support:** See the SDK reference in the packaged `reference` folder for API and CLI details.

This content is sanitized for npm packaging and intentionally omits internal examples and confidential notes.
