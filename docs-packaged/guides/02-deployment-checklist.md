# Deployment Checklist

Keep this checklist handy when deploying the PayWay SDK integration to staging or production.

- Verify API credentials and environment variables are set.
- Confirm webhook endpoints are reachable and use TLS.
- Run local end-to-end smoke tests against sandbox endpoints.
- Verify journal and logging configurations are enabled for troubleshooting.

This checklist excludes internal operations and example scripts that are not packaged.
