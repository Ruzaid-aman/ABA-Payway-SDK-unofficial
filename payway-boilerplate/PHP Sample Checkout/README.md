# PayWay Checkout - JavaScript Implementation

This is a JavaScript/Node.js implementation of the PayWay checkout system, converted from PHP.

## Features

- Node.js/Express backend for secure hash generation
- Clean HTML/JavaScript frontend
- Secure API key handling (server-side only)
- HMAC SHA512 hash generation
- PayWay checkout integration

## Project Structure

```
.
├── server.js           # Node.js Express server
├── config.js           # PayWay API configuration
├── checkout.html       # Checkout page (UI)
├── package.json        # Node.js dependencies
├── logos/              # Payment logos
└── README.md           # This file
```

## Installation

1. Install Node.js (if not already installed)
   - Download from: https://nodejs.org/

2. Install dependencies:
   ```bash
   npm install
   ```

## Configuration

Edit `config.js` to set your PayWay credentials:

- `ABA_PAYWAY_API_URL`: PayWay API endpoint
- `ABA_PAYWAY_API_KEY`: Your PayWay API key (keep secret!)
- `ABA_PAYWAY_MERCHANT_ID`: Your merchant ID
- `PORT`: Server port (default: 3000)

## Running the Application

### Development Mode (with auto-reload):
```bash
npm run dev
```

### Production Mode:
```bash
npm start
```

The application will be available at:

- `http://localhost:3000/`

## How It Works

1. **Frontend (checkout.html - Improved Version)**:
   - Modern, responsive UI with dark mode support
   - Real-time form validation
   - Live amount display
   - Collects payment information
   - Sends data to backend API to generate hash
   - Submits form to PayWay with generated hash
   - Loading states and error handling

2. **Backend (server.js)**:
   - Provides API endpoint `/api/generate-hash`
   - Securely generates HMAC SHA512 hash using API key
   - Returns hash and API URL to frontend
   - Keeps API key secret (never exposed to client)

## API Endpoints

### POST `/api/generate-hash`

Generates a secure hash for PayWay checkout.

**Request Body:**
```json
{
  "req_time": 1702742400,
  "merchant_id": "nie.cambodia",
  "tran_id": "1702742400000",
  "amount": "1000",
  "firstname": "test",
  "lastname": "test",
  "email": "",
  "phone": "012345678",
  "payment_option": "abapay_khqr"
}
```

**Response:**
```json
{
  "success": true,
  "hash": "generated_hash_here",
  "api_url": "https://checkout-sandbox.payway.com.kh/api/payment-gateway/v1/payments/purchase"
}
```

## Security Notes

- ⚠️ **NEVER** expose your `ABA_PAYWAY_API_KEY` to the client side
- The hash generation is done server-side for security
- The API key is stored in `config.js` and only used by the backend
- Use HTTPS in production to encrypt all communications

## Payment Options

- `abapay_khqr`: ABA KHQR payment
- `abapay_khqr_deeplink`: ABA KHQR deeplink (for mobile integration)

## Differences from PHP Version

1. **Server-side hash generation**: The hash is generated by calling a backend API instead of generating it directly in the PHP file
2. **Separation of concerns**: Configuration, server logic, and frontend are separated into different files
3. **Async/await**: Uses modern JavaScript async/await for API calls
4. **RESTful API**: Backend provides a clean REST API for hash generation

## Troubleshooting

- **CORS errors**: Make sure the server is running and CORS is enabled
- **Connection refused**: Check that the server is running on the correct port
- **Invalid hash**: Verify that the hash string is constructed in the correct order
