**Structured version:**

**Title:** PayWay API Postman Collection

**Objective:**  
Build a comprehensive, up-to-date Postman Collection for all APIs and callback webhooks documented at https://developer.payway.com.kh/.

**Purpose:**  
Provide merchant developers with a ready-to-use playground for testing the full PayWay API suite.

**Scope:**  
- Cover all PayWay APIs and callback/webhook events.
- Follow current Postman and API testing best practices.
- Include clear error-code explanations.
- Add pre-request and test/post-response scripts for multiple testing scenarios.
- Support transaction pooling flows.
- Cover all callback and request scenarios.

**Audience:**  
Merchant developers integrating with PayWay.

**Expected Outcome:**  
A practical Postman Collection that enables merchant developers to test all PayWay services end-to-end.
