iOS

Swift & Objective-C support with SPM and CocoaPods

Requirements

iOS 13.0 or later
Xcode 12.0 or later
Swift 5.3 or later
GitHub PAT (Personal Access Token)

Setup Guide

Step 1: Add Package in Xcode

  1. Open Your Project in Xcode
  2. Navigate to File → Add Packages…
  3. Enter Repository URL: https://github.com/ctg-digital/cpg-ios-sdk.git
  4. Provide GitHub credentials (username and PAT)
  5. Select version and target project

Step 2: Import and Use

Swift
import cpg_framework

let security = SecurityWrapper.shared

For more information, visit the GitHub Packages Documentation
