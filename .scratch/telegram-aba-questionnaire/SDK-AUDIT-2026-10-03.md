   expired_at wording, re-authorization guidance, "unknown = scheduled token without a parseable
   delivered expired_at") and display the stored `expired_at=` field.
5. **docs/09** (both mirrors + corpus resync): one sentence stating the SDK split — local renew
   restarts the rolling window for ACCOUNT tokens only and never moves a scheduled token's local

### Considered and DECLINED

- **Honoring the FU-10 "try again in 1min" hint in the retry engine**: business-level 429s are
  retryable and the engine paces them from the endpoint's documented window (1–10s) or exponential
  backoff before surfacing the typed error. Auto-waiting 60s per attempt would hang interactive
  CLI paths for minutes; the typed error already carries the gateway's message. Callers that want
  the 1-minute cooldown should honor it above the SDK.
