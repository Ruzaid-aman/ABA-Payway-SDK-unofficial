# ABA Knowledge Hub — Internal Dossier Index

This index collects the canonical, internal evidence and question registers about ABA PayWay.

Purpose: provide a single place to answer "where is the canonical record for X?" for maintainers and agents.

Canonical mappings

| Question | Canonical answer |
| --- | --- |
| What does the gateway ACTUALLY do (live-verified)? | `docs/internal/SANDBOX-FINDINGS.md` (append-only, §-numbered evidence) |

How to use

- Use the `SANDBOX-FINDINGS.md` §-numbers for in-code references (this file keeps its filename so citations remain stable).
- Do not move or publish files under `docs/internal/`; they are intentionally excluded from the package.
- If you need to update an internal dossier, append a new section with date and evidence and keep the filename unchanged.

If you are preparing a public docs change, consult this hub first and link to the appropriate public guide (docs/guides/*) or to `knowledge/` topics generated by `npm run sync:knowledge`.

Owner: docs working group. For reorg sequencing notes, see `.scratch/docs-reorg/REORG-PLAN.md`.
