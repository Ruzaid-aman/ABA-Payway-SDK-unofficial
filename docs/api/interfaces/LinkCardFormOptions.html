    Interface LinkCardFormOptions

    Rendering options for CredentialsOnFileDomain.getLinkCardFormHtml.

    Deliberately narrower than CheckoutFormOptions: there is no popupMode because the AbaPayway popup plugin (checkout2-0.js, target aba_webservice) is documented for the purchase endpoint only — the link-card flow is a full-page hosted form the customer completes in the same tab (or an iframe the merchant hosts).
