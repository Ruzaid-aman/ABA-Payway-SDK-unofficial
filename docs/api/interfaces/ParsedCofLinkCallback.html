    Optional Readonlyctid

    ctid?: string

    Customer token identifier, when the delivery echoes one.

    Optional ReadonlyexpiredAt

    expiredAt?: string

    Delivered token expiry (expired_at), when present — an ISO-8601 instant on the live capture (§26 AOF-7). Authoritative for scheduled subscription tokens (CITR_FIX/MITR_FIX — FU-08: explicit expired_at, no inactivity rule); unscheduled account tokens stay governed by the 90-day rolling window regardless (T-13), so this field never overrides those.

    ReadonlyextraFields

    extraFields: Record<string, string>

    Every other scalar field on the delivery (minus the hash signature), stringified and preserved verbatim — source_of_fund, type, frequency, subscribed_amount, amount_limit_per_tran, currency on the live shape. (expired_at is surfaced as the first-class expiredAt field above.)

    Readonlypwt

    pwt: string

    The delivered payment token — the delivery's reason to exist.

    Optional ReadonlyrequestId

    requestId?: string

    Link request id, when the delivery echoes one.

    Optional Readonlystatus

    status?: string

    Status field, when present. On the live shape this is the CREDENTIAL status (number, 1 = active) nested in payment_credential — not a transaction status code (Q18 answer; §26 AOF-7).

    Optional ReadonlytokenFlag

    tokenFlag?: string

    Token flag echoed back (CITI_FLEX / CITO_FLEX), when present.
