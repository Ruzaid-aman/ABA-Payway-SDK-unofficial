    constructor

    • new PayWay(config?: Partial<PayWayConfig>): PayWay

      Create a new PayWay SDK client instance.

      Parameters

      • config: Partial<PayWayConfig> = {}

        The SDK configuration options.

        • merchantId

          The merchant ID issued by PayWay.

        • apiKey

          The API key/secret issued by PayWay for signing.

        • publicKeyPem

          The 1024-bit RSA public key PEM string for encrypting request payloads.

        • environment

          The target environment ('sandbox' or 'production'). Defaults to 'sandbox'.

        • timeout

          The request timeout in milliseconds. Defaults to 30,000 (30 seconds).

        • baseUrl

          Optional override for the base API URL.

        • maxRetries

          Number of retries on transient failures (429, 5xx, network). Defaults to 3.

        • retryDelayMs

          Base delay in milliseconds between retries (exponential backoff). Defaults to 3000.

      Returns PayWay

      Throws

      If the configuration is missing or invalid.

    Accessors

    apiBaseUrl

    • get apiBaseUrl(): string

      Effective base URL of the resolved environment (config override or BASE_URLS[environment]) — lets local-only callers (e.g. the CLI's cof token-flag-sweep card leg) POST to a hosted endpoint directly without duplicating the env-resolution logic.

      Returns string

    journal

    • get journal(): JournalContext | undefined

      The client's journal emitter — undefined unless journaling is enabled (config journal / PAYWAY_JOURNAL). Lets hosts (CLI, agent) emit command-level events into the same journal file as the transport events.

      Returns JournalContext | undefined

    lastCorrelationId

    • get lastCorrelationId(): string | undefined

      Correlation id (cid) of the most recent API exchange. Callers and the agent layer use it to join their own records with the transaction journal (every journal event carries the same cid).

      Returns string | undefined

    lastTraceId

    • get lastTraceId(): string | undefined

      Gateway status.trace of the most recent successful exchange, when the envelope carried one (improvement I-2: surfaced for stdout↔journal joins).

      Returns string | undefined
